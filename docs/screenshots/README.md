# Screenshot sources

The `0.9.01-*` and `theme-*` images show the current C# Adventure launcher. The adventure, save-editor, and theme views use example profiles and a captured game scene, with inventory artwork displayed from a local Hookshot installation. The screenshots do not contain personal save files or the generated icon cache.

- `0.9.01-adventures.png` and `0.9.01-details.png` show profile selection and the save summary.
- `0.9.01-save-editor.png` shows in-place editing and scale choices.
- `0.9.01-randomizer.png`, `0.9.01-cosmetics.png`, and `0.9.01-install.png` show settings and setup.
- `theme-*.png` show all eight themes in the current launcher.
- `themes-showcase.png`, `adventure-select.png`, `adventure-details.png`, `installer.png`, and `manage-saves-preview.png` are earlier v0.8 launcher images preserved for reference.

These are illustrative UI captures. Extracted textures, game files, saves, and icon caches are not included.
